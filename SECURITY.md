# Security

## Reporting a vulnerability

Please report security issues **privately** — do not open a public issue:

1. Go to <https://github.com/alanvardy/orksorksorks>.
2. Use the **Report a vulnerability** button (Security → Advisories → New
   advisory) to disclose the issue privately.
3. Include enough detail to reproduce: affected command, config, and
   observed behavior.

You will receive an acknowledgment that the report was received. The
maintainer will respond with a fix and a coordinated-disclosure timeline;
please keep details private until a patch is released.

## Supported versions

Only the latest release is supported. The project is pre-1.0 (`0.x`), so fixes
land in the next release rather than backport branches.
