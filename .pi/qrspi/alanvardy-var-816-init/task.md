# Task — VAR-816: init

Add an `init` subcommand to the `orksorksorks` CLI. Running `orksorksorks init` should create an empty `orksorksorks.toml` file in the current directory and print a confirmation message to the terminal. Command-line parsing is handled with clap.

This is the first real feature in the freshly scaffolded project and will establish the CLI's structure, error handling, output, and testing conventions that subsequent subcommands will follow.
